# 商会 BI 数据维护

## 文件分工

- `data/商会BI数据.xlsx`：唯一需要人工维护的 Excel 数据源。
- `data/members.json`：网页读取的公开数据，由脚本自动生成。
- `scripts/refresh_data.py`：把 Excel 转成网页数据。
- `index.html`：只负责页面展示和交互，不再内嵌会员明细数据。

## 更新数据

1. 打开 `data/商会BI数据.xlsx`，只编辑 `会员数据` 工作表。
2. 保留第一行表头，不要修改必要列名称。
3. 执行：

```powershell
python scripts/refresh_data.py
```

4. 用本地服务器预览 `index.html`，确认无误后再发布整个网页目录。

脚本只会输出页面所需的公开字段，不会把电话、生日、身份证号等敏感字段写入 `members.json`。

## 必要列

`会员姓名`、`会内职位`、`单位名称`

地图和统计建议同时维护：

`性别`、`年龄段`、`政治面貌分类`、`所属行业`、`区域`、`城市`、`注册地址`、`申请年份`、`lng`、`lat`、`好人好事标记`
