# 沈阳市年轻一代民营企业家商会 · 会员数据看板

深空玻璃拟态（Dark Glassmorphism）风格的商会 BI 看板：会员结构、地理分布、行业构成、入会趋势与会员明细。
纯静态站点，无需后端，可直接托管在 GitHub Pages。

---

## 1. 目录结构

```
index.html                  页面骨架（不再内嵌数据与样式）
assets/css/main.css         视觉系统（配色、玻璃卡片、响应式）
assets/js/app.js            数据加载、筛选联动、图表、表格、抽屉
assets/js/geo.js            辽宁省 / 沈阳市行政区划边界（离线）
assets/vendor/echarts.min.js  ECharts 5.5（本地化，不依赖 CDN）
assets/img/logo.jpg         商会会徽
data/members.json           由脚本生成的网页数据
（Excel 数据源不入库，放在仓库外，见下方「更新数据」）
data/legacy_coords.json     旧版人工校正过的区域与经纬度（脚本会优先采用）
scripts/refresh_data.py     Excel → JSON 数据管道
```

> 相比旧版：ECharts 改为本地文件，即使断网或 CDN 被墙也不会出现「图表库加载失败」。

## 2. 更新数据（三步）

1. 打开你本地的 `商会分布地图（261111）.xlsx`，编辑 **会员总表 / 考核明细表**（保留第一行表头）。
2. 执行（Excel 放在仓库外，用路径传入）：

   ```powershell
   python scripts/refresh_data.py "D:\360MoveData\Users\Admin\Desktop\商会分布地图（261111）.xlsx"
   ```

   也可以把文件放到 `data/商会BI数据.xlsx`，然后直接 `python scripts/refresh_data.py`。
3. 刷新网页即可。

> Excel 含电话、生日、身份证，`.gitignore` 已排除 `data/*.xlsx`，**不会**随仓库发布。

脚本会自动派生这些字段，Excel 里不需要手工维护：

| 派生字段 | 来源 |
| --- | --- |
| 年龄 / 年龄段 | 生日（按运行当天计算） |
| 申请日期 / 申请年份 / 会龄月 | 申请时间（支持 `2020.2.24` 与日期格式） |
| 政治面貌归类 | 中共党员 / 民主党派 / 无党派人士 / 共青团员 / 群众 |
| 职位归类 | 会长 / 副会长（含「副会长兼秘书长」）/ 理事（含「副秘书长\理事」）/ 会员 / 其他（第一届原副会长、独立监事、秘书处工作人员） |
| 理事会成员 | 除「会员」和「第一届原副会长」之外的全部人员，当前 74 人 |
| 生日月 | 只输出月份（用于生日会排期），不输出具体日期 |
| 区域 / 城市 / 经纬度 | 优先沿用 `legacy_coords.json` 的旧版校正值；新成员从注册地址解析并落到区县中心点 |
| 好人好事 / 好事数 | 好人好事列非空即为「是」，按分号拆条计数 |

隐私：脚本只输出页面需要的公开字段，**电话、生日、身份证号不会写入 members.json**。

### 补充数据（可选）

如果要做「在册率 / 活跃度 / 企业规模」这类指标，建议**直接在同一个 xlsx 里新增工作表**（脚本按表名读取，比单独的文件更省事）。推荐结构：

- `缴费记录`：会员姓名、年度、应缴金额、实缴金额、缴费日期、到期日
- `活动签到`：活动名称、活动日期、会员姓名、是否参加
- `企业规模`：会员姓名、注册资本（万元）、员工人数、年营收（万元）、成立年份

统一用「会员姓名」作为主键（如有重名，再加一列「序号」）。给我表之后我会补脚本和对应图表。

### 统计口径

- **副会长 19 人** = 副会长 18 + 副会长兼秘书长 1
- **理事 52 人** = 理事 49 + 副秘书长\理事 3
- **理事会成员 74 人** = 会长 1 + 副会长 19 + 理事 52 + 独立监事 1 + 秘书处 1，即「除会员与原第一届副会长外的全部人员」
- **其他 5 人** = 第一届原副会长 3 + 独立监事 1 + 秘书处工作人员 1（在明细里仍显示原始职务）
- 会员明细默认按 Excel 的「序号」顺序展示，点表头才会重新排序
- **会费状态**：取「会费缴纳情况」里所有「起止日期」中最后一个结束日作为到期日；到期日 ≥ 今天为「有效」，否则「已到期」，没有日期为「未登记」
- **年度考核**：来自「商会会员考核明细表」，按姓名匹配；「得分」取年度总分，「活动」取常规次数 + 加分-活动次数（合计 519 人次，人均 2.6 次）
- **企业画像**：企业标签来自「企查查查询」列（高新技术企业、专精特新、科技型中小企业、小微企业、雏鹰、瞪羚、小巨人、国有企业），点击标签可查看对应企业名单并继续点开会员详情；规模取注册资金、员工数、最近一年纳税额
- **到龄关注**：45 岁以上人数单独统计，卡片只显示 43–47 岁的年龄结构（公开场合不出现姓名）；需要跟进时点「导出名单」，导出 43 岁以上会员的姓名 / 年龄 / 区域 / 职位 / 入会时间。年龄按运行当天计算，重跑脚本会更新。

### 内部模式

顶栏「内部模式」开关，**默认关闭**。开启后三张卡片会从图表切换为名单：

- 到龄关注：43 岁以上会员的姓名 / 区域 / 年龄
- 会费状态：已到期与 90 天内到期的会员名单
- 年度考核：考核前 5 与后 5 位（用于内部沟通，不建议投屏）

开关状态存在 `sessionStorage`，刷新页面保持、关闭浏览器自动失效；投屏或对外演示前请关掉。

## 3. 本地预览

`members.json` 通过 `fetch` 加载，直接双击 `index.html`（file://）会被浏览器拦截，请用本地服务器：

```powershell
cd 项目目录
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

或者用 VS Code 的 Live Server 插件。

## 4. 发布到 GitHub Pages

1. 把 `index.html`、`assets/`、`data/`、`scripts/` 覆盖到仓库 `liujinling00/shanghui-bi` 的根目录；
2. 提交并推送：

   ```powershell
   git add -A
   git commit -m "新版会员数据看板 + 数据更新（210 人）"
   git push
   ```

3. 等待 1–2 分钟，刷新 https://liujinling00.github.io/shanghui-bi/ （建议 Ctrl+F5 清缓存）。

## 5. 页面功能

- **全局筛选**：职位 / 行业 / 区域 / 入会年份 / 性别 / 关键词搜索，所有卡片与图表实时联动。
- **地图**：沈阳市 13 个区县热力 + 会员点位（会长 / 副会长带脉冲），可切换到辽宁省 14 个地市；滚轮缩放、拖拽平移；右侧区县排行可点击直接筛选。
- **核心指标**：在册会员、会费有效、女性会员、中共党员、理事会成员、公益参与，支持「＋自定义指标」（保存在浏览器 localStorage）。
- **图表**：行业分布（可切「门类 / 细分」）、年龄结构、政治面貌、组织结构、入会趋势（可切「年度新增 / 入会年龄」）、行业 × 区域交叉热力图。
- **洞察行**：会员会龄、生日月份、公益贡献 TOP、到龄关注（只展示年龄结构，不点名；名单通过「导出名单」下载 CSV）。
- **治理行**：会费状态（有效 / 已到期 / 未登记）、年度考核（可切「得分 / 活动」，活动为参与次数分布）、企业画像（标签可点击查看企业名单）。
- **会员明细**：表头排序、分页、关键词过滤、CSV 导出（带 BOM，Excel 直接打开不乱码）、点击行查看详情抽屉。
- **其它**：右上角全屏展示、刷新数据、深链 `?member=序号` 直接打开某位会员、`?static=1` 关闭数字滚动动画（截图/投屏用）。

## 6. 两个版本

- 内部版：当前目录，含全部数据，给理事会/秘书处。
- 公开版：运行 `python scripts/build_public.py`，会在同级生成 `shanghui-bi-public/`，自动移除会费、考核、活动次数、生日月份、企业财务等 17 个字段，并隐藏相关卡片与「内部模式」。

公开版目录不含 Excel 源文件与脚本，可直接上传到 GitHub Pages / Netlify。
